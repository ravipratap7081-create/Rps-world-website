# RPS World

Website for **RPS World** — the web agency of Ravi Pratap Singh (Kanpur, India).

Fast, mobile-first websites for small businesses, shops and weddings, plus free PDF & image tools.

**Live site:** https://rpsworld.in

## What it is

- **Websites for small businesses** — mobile-first, built to be found and to make contact easy.
- **Wedding invitations** — live demo sites (see Nyota).
- **Free tools** — ProTools: free PDF & image tools that run in the browser, no sign-up.

Related projects:

- **ProTools** — free PDF & image tools: https://protools.rpsworld.in
- **Nyota** — wedding-invitation demo: https://nyota.rpsworld.in

## Stack

- Next.js 14 (App Router) + React 18
- Tailwind CSS 3
- Supabase (`@supabase/ssr`, `supabase-js`)

## Run locally

```sh
npm install
cp .env.example .env.local   # fill in your own values
npm run dev                  # http://localhost:3000
```

Build and start:

```sh
npm run build
npm run start
```
